# Proposta para `/affiliates`

Os itens abaixo permanecem como `To be confirmed` na página. Aprovar antes de
publicar condições, pagamentos ou regras de participação.

| Item                   | Proposta para decisão                                                                                                                                                                                                                    |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Comissão               | Definir percentual, linhas/produtos elegíveis, atribuição por link/código, recorrência de assinaturas, reembolsos, cancelamentos, estornos, impostos e limites. Os 15% do board estão marcados como exemplo e não foram publicados.      |
| Cupom de audiência     | Decidir se haverá cupom, desconto, elegibilidade, combinações, limites e prazo. Não há cupom na página atual.                                                                                                                            |
| Amostras e produtos    | Definir se haverá produto gratuito, processo de seleção, custos e disponibilidade por mercado.                                                                                                                                           |
| Link, código e painel  | Definir domínio e formato do link, emissão de código, atribuição, painel, analytics, duração de cookie e acesso aos dados de cliques/vendas.                                                                                             |
| Pagamentos             | Definir periodicidade, método, moeda, limite mínimo, documentos fiscais e janela para reembolsos/estornos. O pagamento mensal do board não foi tratado como aprovado.                                                                    |
| Critérios e revisão    | Aprovar nichos, tamanho/qualidade de audiência, plataformas aceitas, processo de aprovação, prazo, critérios de recusa e recurso. O texto de mínimo de seguidores do board não foi publicado como regra.                                 |
| Diretrizes de conteúdo | Revisar juridicamente regras de alegações structure/function, divulgações de parceria, anúncios pagos, conteúdo de saúde humana e animal, uso de marca e processo de remoção. Até aprovação, a página não publica exemplos ou alegações. |
| Depoimentos e exemplos | Fornecer relatos reais com autorização e prova, caso sejam desejados. Nenhum depoimento, caption ou resultado fictício foi incluído.                                                                                                     |
| Termos e privacidade   | Redigir termos de afiliados, disclosures, retenção/uso de handles e links, propriedade intelectual, encerramento e contato de privacidade.                                                                                               |
| Contato                | Confirmar e-mail do time de creators. `creators@nadeonlabs.com` no board está marcado como exemplo; por enquanto, o link usa `/help#contact`.                                                                                            |
| Linha de produto       | Definir participação em Human, Pet ou ambas e produtos permitidos, incluindo linhas de suplementos para animais.                                                                                                                         |

O formulário envia os campos pelo `formsProvider` existente. A integração live
continua sendo stub até uma tarefa de integração específica.
