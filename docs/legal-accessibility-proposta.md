## 2. Conformidade e Decisões de Implementação

1. **Passo 8 do Briefing W2:** Todo placeholder do board virou `"To be confirmed"` no JSX/TSX. Nenhum dado fictício ou número inventado foi incluído como texto fixo no código.
2. **Semântica e HTML Nativo:**
   - Formulário de feedback com elementos `<form>`, `<label>`, `<input>`, `<select>`, `<textarea>` e `<button type="submit">`.
   - Navegação por seções ("On this page") com âncoras acessíveis (`#our-commitment`, `#standards-we-follow`, etc.).
   - Em mobile, sumário expansível via `<details>` e `<summary>`.
   - Todos os alvos clicáveis possuem dimensão mínima de 44 × 44 px.
   - Foco visível com `focus-visible:ring-2 focus-visible:ring-accent`.
3. **Integração de Formulário:**
   - Server Action `submitAccessibilityFeedback` em `_components/actions.ts` consome `formsProvider.sendContact` com `topic: "accessibility"`, validado com Zod.
   - Componente de cliente importa estritamente de `lib/providers/client` e Server Actions conforme Regra 13.
